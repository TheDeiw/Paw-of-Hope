# 🐾 Paw of Hope — Платформа з порятунку безпритульних тварин 

##  Про проєкт
### ***Paw of Hope*** — це платформа, створена для розміщення та поширення інформації про тварин, які залишились без нагляду внаслідок війни. 

Платформа дозволяє притулкам та волонтерам спільно працювати над порятунком тварин: від публікації оголошень до передачі знайдених тварин та збору донатів.

Наразі це *клікабельний прототип*, який демонструє основний функціонал платформи. У майбутньому ми прагнемо розвинути Paw of Hope у повноцінну екосистему для порятунку тварин із мобільним додатком, інтеграцією з соцмережами, верифікацією організацій та іншими корисними функціями.

>  Проєкт реалізований у межах тестового завдання без back-end логіки. Усі дані та мінімальна функціональність моделюються на фронтенді.

## Інструкція з запуску локально
1) ***Склонуйте або завантажте репозиторій***:  

Склонуйте репозиторій за допомогою команди:
  ```bash
  git clone git@github.com:TheDeiw/Paw-of-Hope.git
  ```
Або завантажте ZIP-архів із кодом із GitHub та розпакуйте його.

2) ***Перейдіть до папки проєкту:***
```
cd Paw-of-Hope
```
3) ***Відкрийте прототип локально:***
 
 Якщо ви не використовуєте сервер, просто відкрийте файл index.html у браузері:
- Знайдіть файл index.html у папці проєкту.
- Двічі клацніть на файлі, або перетягніть його у вікно браузера.

Прототип запуститься, і ви зможете взаємодіяти з усіма елементами інтерфейсу.

4) ***Розгортання на локальному сервері (опціонально):***

Якщо ви хочете запустити проєкт через локальний сервер:
- Скопіюйте папку проєкту до директорії вашого локального сервера (наприклад, htdocs для XAMPP).
- Запустіть сервер (наприклад, через XAMPP запустіть Apache).
- Відкрийте браузер і перейдіть за адресою http://localhost/paw-of-hope.

5) ***Перегляд прототипу:***

Після запуску ви зможете ознайомитися з основними функціями: реєстрація, створення оголошень, перегляд профілю, пошук тварин та організацій.

##  Основні функції платформи
###  Реєстрація та ролі користувачів: 
- При натисканні кнопки **"Реєстрація"** відкривається форма, де користувач вказує необхідну інформацію: ім'я, email, номер телефону, область та пароль
- Користувач має можливість або зареєструвати власний акаунт волонтера, або зареєструвати акаунт закладу, де в свою чергу потрібно обрати категорію закладу
  - *Можливості волонтера:*
    1) шукати різні заклади, які займаються порятунком тварин;
    2) шукати улюбленців за потрібними користувачу категоріями;
    3) публікувати власні оголошення про знайдених творин;
    4) зберігати вподобані тваринки та заклади;
    5) надсилати запити про передачу тваринки до закладу або про бажання прийняти тваринку у свій дім, можливість спілкуватися з організаціями;
    6) надавати фінансову підтримку закладам/організаціям через донати;
  - *Можливість закладу/організації:*
    1) шукати інші заклади;
    2) шукати улюбленців від інших закладів та волонтерів;
    3) публікувати картки улюбленців, за які відповідає заклад;
    4) переглядати запити від волонтерів, спілкуватися з ними;
    5) вказує інформацію для збору коштів, донатів

<br></br>

###  Особистий кабінет волонтера: 
Після створення оголошення користувач потрапляє до особистого кабінету, який складається з кількох вкладок:
- `Оголошення:` список усіх створених карток тварин із можливістю перегляду, додавання нових карток або їх видалення;
- `Вподобані:` збережені картки тварин і організацій, які користувач позначив як цікаві;
- `Чат:` канал для безпосередньої комунікації між волонтерами та організаціями;
- `Профіль користувача:` відображає фотографію, коротку біографію, контактні дані. Є можливість редагування профілю (змінити зображення, біо, додати або забрати номер телефону та email). Також є допоміжні кнопки `Налаштування` та `Вийти з акаунту`;

Коли на цей акаунт буде заходити інший акаунт, то йому буде доступна вся інформація (без кнопок для редагування або зміни профілю) з вкладки `Профіль користувача` та вкладка `Оголошення`

<br></br>

###  Особистий кабінет організації/закладу:
Користувача, що створив акаунт закладу, при переході на свій профіль бачитиме такі вкладки:
- `Список тварин:` список усіх тварин, які перебувають на утриманні, з можливістю перегляду, додавання нових улюбленців та їх видалення;
- `Чат:` для перегляду поданих заявок від волонтерів та спілкування з ними;
- `Профіль користувача:` такі ж дані та можливості, як і у волонтера, проте ще є можливість додавати/редагувати місцезнаходження та надавати реквізити банківської карти для отримання донатів;

При переході на цю сторінку як відвідувач профілю, йому будуть доступні вкладки `Профіль користувача` (без можливості редагування та зміни профілю), `Список тварин` та додаткова можливість `Подати заявку:` для створення оголошення про знайденого улюбленця, аби передати його на утримання в дану організацію

<br></br>

###  Створення оголошення:
Зареєстровані користуваці можуть створювати картики улюбленців за допомогою відповідної вкладки у заголовку сайту, або за допомогою кнопки ***Додати*** (*волонтери* на вкладці `Оголошення`, а заклади - `Список тварин` власних профілів) 

- При переході на вкладку `Створити оголошення` відкривається інтерактивна форма;
- У формі вказуються детальні дані, такі як: Ім'я тварини, вид, стать, вік, стан здоров’я, статус стерилізації, область перебування, короткий опис, фото, номер телефону та ім’я контактної особи;
- Після створення оголошення воно додається до загального списку, стаючи доступним для пошуку іншими користувачами.

<br></br>

###  Пошук тварин:
- Розділ "Знайти тваринку" містить усі активні картки, створені волонтерами та організаціями;
- Реалізована система фільтрів: вид, стать, вік, область, стан здоров’я;
- Доступний пошук за ключовими словами для швидкого знаходження релевантних оголошень;
- Кожна картка містить базову інформацію: фото, ім’я, вік, стать (та ж інформація, що заповнювалась при створення оголошення). При кліку відкривається - детальний опис із можливістю зв’язатися з автором оголошення;
- Користувач може вподобати тваринку або одразу написати автору оголошення, щоб подарувати їй дім;

<br></br>

###  Пошук організації:
- У розділі "Пошук організацій" зібрані всі партнери платформи: притулки, ветклініки, розплідники, зоозахисні ініціативи;
- Доступний пошук за назвою або фільтрація за областю для зручного знаходження найближчих установ;
  
<br></br>

###  Додаткові можливості:
Як і зареєстровані користувачі, так і відвідувачі платформи можуть преглянути:

- `Новини:` перегляд оновленнь, історій успіху та ініціатив;
- `Про нас:` інформація про творців платформи, їх історію задуму та створення цього продукту, місії та статистика про кількість улюбленців, що знайшли домівку, кількість зібраних коштів на пожертви та кількість організацій співпрацювання;
